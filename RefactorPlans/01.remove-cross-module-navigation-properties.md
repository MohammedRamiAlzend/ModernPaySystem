# Step 1: Remove Cross-Module Navigation Properties from Entities

Remove all navigation properties from Transaction module entities that reference entities owned by the Identity module (User, Department). Keep the scalar FK properties (e.g., `RequesterId`, `DepartmentId`) — only delete the navigation properties.
